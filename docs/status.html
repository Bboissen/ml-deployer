Next Commands

Local path, if you want to rerun it:

make head-start make local-lab-up WORKER_COUNT=3 make ray-status EXPECTED_WORKERS=3 make smoke EXPECTED_WORKERS=3 make tune-synth make watch-once make local-lab-down make head-stop

Paid DigitalOcean smoke path, if you want to rerun it:

make head-start TF=$HOME/.local/bin/tofu make do-up DO_WORKER_COUNT=1 make ray-status EXPECTED_WORKERS=1 make smoke EXPECTED_WORKERS=1 TF=$HOME/.local/bin/tofu make do-down make head-stop

Three-worker smoke path:

make head-start TF=$HOME/.local/bin/tofu make do-up DO_WORKER_COUNT=3 make ray-status EXPECTED_WORKERS=3 make smoke EXPECTED_WORKERS=3 TF=$HOME/.local/bin/tofu make do-down make head-stop

make do-up creates paid DigitalOcean resources. make do-down now attempts Tailscale logout before destroying workers.
